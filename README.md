# The Cube of Ghukliak

A goblin relic for the table. One stone tablet, one blue hologram, and a password.

The cube is published from `main` to GitHub Pages:

https://xenodorian.github.io/The-Cube-of-Ghukliak/

Open that address in a browser. The stone along the bottom is the Ghukliak alphabet. The light above it is the record.

Do not put the password in this file.
